## Dependencies
- Day 03–06 cannot promote art before Day 02 identity lock.
- Day 09/26 cannot finalize hazards before Day 07 movement measurements.
- Day 13–17 must use image-authored finished UI.
- Day 20–23 require book evidence before animation production.
- Day 25 depends on comic grammar + portrait packages.
- Day 29 cannot pass with P0/P1 defects.

## Evidence required to close any gate
1. canonical binaries in `rizaaltun/catpat2`,
2. manifest/source changes,
3. runtime integration where applicable,
4. transactional QA evidence,
5. daily/gate report,
6. exact commit SHA(s),
7. open risks for the next gate.

Documentation alone cannot close two consecutive production gates when binary/runtime output was scheduled.
