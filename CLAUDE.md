# Catpat2 continuity rules

ChatGPT is the active owner of art, animation, gameplay, story, code and testing until the user explicitly requests a Claude handoff. Work on `chatgpt/development`; do not merge `main` or change deployment/Cloudflare/domain settings.

Start by reading `docs/DEVELOPMENT_STATUS.md` and `manifest.json`. The source book is private reference material and must not be uploaded wholesale to this public repository. Character art must stay faithful to the book. Real delivered files and measured tests are required before marking work complete.
